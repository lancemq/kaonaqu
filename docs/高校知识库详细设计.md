# 高校知识库（Universities Channel）详细设计

> 版本：v1.0 · 2026-10-29 · 状态：待评审
> 需求：收录全国各地高校数据；**高校专题页不区分地区，所有地区看到同一个系统**（单一 URL 空间，无 /{region} 前缀）。
> 阅读对象：开发 / 架构。对齐《docs/详细设计.md》与《docs/new-city-playbook.md》的既有约定。

---

## 1. 需求与定位

### 1.1 背景
现有三频道（新闻/学校/知识）均为**地区频道**：URL 带 `/{region}` 前缀、内容由 region 隔离。而高考出口（高校）天然是全国维度——上海/苏州/南京/无锡四个 region 的用户报考的是同一批全国高校。因此高校频道做成**全局频道**：

- 单一 URL：`/universities/...`，无地区前缀、无地区重定向
- 所有地区导航一致入口，内容完全一致
- 数据模型与页面均不携带 region 概念

### 1.2 目标用户与价值
- 高考生/家长：查全国高校（是什么层次、有什么学科、在本省多少分能上）
- 与现有频道的协同：学校频道高中详情页的 `outcome_stats`（高考落点）未来可反链高校详情；新闻 gaokao 专题挂高校入口

### 1.3 非目标（本期不做）
- 高校之间的深度对比工具（M3）
- 分数线选校推荐引擎（M3）
- 研究生院/学科排名体系以外的排名数据（软科/校友会等商业排名不收录）
- 成人高校（仅收录普通高等学校 2868 所）

## 2. 关键决策（D1~D7）

| # | 决策 | 结论 | 理由 |
|---|------|------|------|
| D1 | URL 空间 | **`/universities` 全局路由**，不加 region 前缀 | 单一 canonical，SEO 权重集中；四个 region 重复一套内容会造成 4 份重复页 |
| D2 | proxy 放行 | proxy.js 首段白名单加 `universities`，直接放行不重定向 | 现有逻辑会把无前缀路径 308 到 `/shanghai/...`，必须显式豁免 |
| D3 | region features | **不进** regions.data.json 的 features 门控 | 全局频道对所有地区默认开放；进 features 反而引入"某地区关闭高校"的伪需求 |
| D4 | 收录范围 | 教育部最新名单**全量骨架**（本科 1308 + 专科 1560 = 2868 所），enrichment 优先双一流 147 所 | 名录导入便宜（一次导入）；专科内容深度后置，不阻塞主线 |
| D5 | 主键锚点 | `moe_code`（教育部标识码）为稳定唯一锚点 + 中文 slug `{省份}-{校名}` 为对外 id | 校名会改（民转公、更名潮），标识码不变；slug 风格与 schools 频道一致（中文 slug） |
| D6 | 录取线 v1 | 双一流 147 所 × 用户核心省份（上海/江苏起步），存校内 `score_lines` jsonb（复合键 省份+年份+科类+批次）；**v2 再拆独立表** | 分省全量 = 2868×31×3 年 ≈ 27 万条，v1 场景撑不起；jsonb 复合键合并模式已在 schools 流水线验证 |
| D7 | 内容渲染 | 复用 `components/BlockRenderer.js` 的 `renderBlocks()` 与 content blocks schema | 新闻/学校详情同源渲染层已验证；高校 content 用同一 schema（heading/paragraph/list/quote/divider/markdown） |

### 3.3 proxy.js 改动（唯一侵入点）

```js
// 首段白名单：全局频道（跨地区共享，不参与 region 重定向）
const GLOBAL_CHANNELS = new Set(['universities']);

export function proxy(request) {
  const { pathname } = request.nextUrl;
  if (pathname === '/') { /* 保持现状 */ }

  const match = pathname.match(/^\/([a-z][a-z0-9-]*)(\/.*)?$/);
  if (match) {
    const firstSegment = match[1];
    if (GLOBAL_CHANNELS.has(firstSegment)) {
      // ★ 全局频道：列表页进 CDN 边缘缓存名单（同 schools 列表策略）
      const rest = match[2] || '/';
      const response = NextResponse.next();
      if (rest === '/' ) {
        response.headers.set('Cache-Control',
          'public, s-maxage=1800, stale-while-revalidate=3600');
      }
      return response;
    }
    if (isKnownRegion(firstSegment)) { /* 保持现状 */ }
  }
  /* 保持现状：308 → /{DEFAULT_REGION}{pathname} */
}
```

要点：
- `GLOBAL_CHANNELS` 是 Set，未来若出现第二个全局频道（如专业库）只加一项
- **不进** `CDN_CACHED_LIST_PATHS` 现有 Set（那是 region 频道 rest 路径匹配，语义不同），单独判断
- matcher 正则不用改（已覆盖 `/universities`，只是函数内白名单放行）

### 3.4 导航与入口

各 region 首页导航（`app/[region]/page.js` 208-210 行模式）追加：

```jsx
<RegionLink href="/news">新闻</RegionLink>
{features.schools && <RegionLink href="/schools">学校</RegionLink>}
{features.knowledge && <RegionLink href="/knowledge">知识</RegionLink>}
<a href="/universities">高校</a>   {/* ★ 全局频道：绝对路径，不用 RegionLink（RegionLink 会加 region 前缀） */}
```

所有 region 一视同仁（无 features 判断）。详情页/列表页头部面包屑同理，返回链接用 `/universities` 绝对路径。

## 4. 数据模型

### 4.1 主表 `universities`（migration: `019_create_universities.sql`）

| 列 | 类型 | 说明 |
|---|---|---|
| id | BIGSERIAL PK | 内部 id |
| slug | TEXT UNIQUE NOT NULL | 对外 id：`{省份简称}-{校名}`，如 `北京-清华大学`；同名跨省自动天然消歧；同省同名（极罕见）追加城市前缀 |
| moe_code | TEXT UNIQUE | 教育部标识码（10 位），**更名后保持稳定的锚点**；导入时校验唯一 |
| name | TEXT NOT NULL | 现校名 |
| aliases | JSONB `[]` | 曾用名/简称，如 `["清华","清华大学(211工程)"]`，搜索召回用 |
| province | TEXT NOT NULL | 省份（受控：31 省市区标准名） |
| city | TEXT NOT NULL | 城市 |
| is_undergrad | BOOLEAN | true=本科 / false=专科（高职） |
| nature | TEXT | 受控词表：`公办`/`民办`/`中外合作` |
| affiliation | TEXT | 隶属：`教育部`/`工信部`/`其他部委`/`省级`/`市级`/`军队`（受控词表） |
| tags | JSONB `[]` | 受控词表：`双一流`/`985`/`211`/`强基计划`（一流学科明细不进 tags，进 disciplines） |
| disciplines | JSONB `[]` | `[{name:"计算机科学与技术", rating:"A+", round:4}]`，第四轮学科评估口径 |
| founding_year | INTEGER | |
| address / website | TEXT | |
| content | JSONB `[]` | **与 schools 同构 blocks**（heading/paragraph/list/quote/divider/markdown），BlockRenderer 直接渲染 |
| score_lines | JSONB `[]` | **分省复合键**：`[{province:"江苏", year:2026, track:"物理类", batch:"本科批", min:668, minRank:99, note}]`；复合键 = province+year+track+batch，只增不覆盖（同 schools 年份复合键纪律） |
| outcome_stats | JSONB `[]` | 预留（升学率/深造率等官方就业质量报告指标），v1 不填 |
| profile_depth | TEXT | `basic`/`foundation`（对标 schools 口径） |
| info_verified | BOOLEAN | |
| created_at / updated_at | TIMESTAMPTZ | |

索引与 RLS（对齐 schools 表）：

```sql
CREATE INDEX idx_universities_province    ON public.universities(province);
CREATE INDEX idx_universities_undergrad   ON public.universities(is_undergrad);
CREATE INDEX idx_universities_tags_gin    ON public.universities USING GIN(tags);
CREATE INDEX idx_universities_name_trgm   ON public.universities USING GIN(name gin_trgm_ops);
-- RLS：anon 读 / service_role 写（同 schools policy 对）
```

### 4.2 出口清洗
高校表**不设** admission_info.notes 审计链（学校频道的内部维护机制），减少一个出口清洗面。内部备注走 `audit_notes` 独立列（默认 `''`），`shared/university-store.js` 的 public 序列化函数统一剔除——沿用"新增对外出口必须接清洗"的红线。

### 4.3 受控词表（对齐 schools 的词表纪律）

| 字段 | 词表 |
|---|---|
| nature | 公办 / 民办 / 中外合作 |
| affiliation | 教育部 / 工信部 / 其他部委 / 省级 / 市级 / 军队 |
| tags | 双一流 / 985 / 211 / 强基计划 |
| province | 31 省市区标准名（与行政区划一致，含"自治区/直辖市"全称） |
| disciplines.rating | A+ / A / A- / B+ / B / B- / C+ / C / C-（第四轮口径） |
| score_lines.track | 物理类 / 历史类 / 综合改革（3+3）/ 不分科 |
| score_lines.batch | 本科批 / 专科批 / 提前批 / 特殊类型招生 |

词表校验进 tests（`tests/universities-schema.mjs`，对标现有 tests 套路）。

## 5. 页面设计

### 5.1 列表页 `/universities`

- **筛选器**（URL query 即状态，对标 schools 列表）：
  - 层次：双一流 / 985 / 211 / 本科 / 专科（多选 tags）
  - 省份（31 + 全部）
  - 性质：公办 / 民办 / 中外合作
  - 隶属：教育部 / 工信部 / 其他部委 / 省级 / 市级 / 军队
- **搜索**：校名/别名 trgm 模糊（复用 schools 的 name_trgm 方案）
- **排序**：默认综合（tags 权重 双一流>985>211>普通，同权按拼音）、建校年份、校名
- **卡片**：校名 + tags 徽章（双一流金色/985/211 灰蓝）+ 省市 + 隶属 + 一句话简介（content 首段截断）
- **缓存**：读 searchParams 动态渲染 + proxy 边缘缓存（同 schools 列表 Fluid CPU 策略，每个筛选组合独立 CDN key）

### 5.2 详情页 `/universities/[slug]`

区块自上而下：

1. **头部**：校名 + 英文名/简称 + tags 徽章 + 省市·隶属
2. **基本信息卡**：建校时间 / 性质 / 隶属 / 官网（外链 nofollow）/ 地址
3. **学校概览**：content blocks（BlockRenderer 渲染，schema 与学校详情同源）
4. **学科实力**：第四轮学科评估 A 类列表（disciplines 按评级排序）
5. **录取数据**（v1 仅双一流校有数据）：省份 tab（query param，不改 URL 路径），按 年份×科类×批次 表格；无数据省份显示"暂未收录"
6. **相关推荐**：同省同层次 6 所（列表页筛选链接）

**渲染策略**：ISR `revalidate = 86400`，不用 `generateStaticParams` 全量预渲染（2868 所会拉长 build；按需 ISR + CDN 兜底，与 schools 详情页策略对齐）。

### 5.3 频道换肤
`body[data-page="universities"]` 重写强调色（建议深蓝 `#1e40af`——与 news 玫红/schools 青绿/knowledge 紫区分），CSS 文件 `styles/channels/universities.css`，规则只重写强调色变量，不复制布局（对齐既有频道换肤纪律）。

## 6. 数据流水线

### 6.1 Seed 导入（一次性）

```
教育部《全国高等学校名单》(最新) 
  → tmp/build-universities-seed.cjs（解析名录，生成 2868 所骨架 JSON）
  → tmp/import-universities.cjs [--exec]（createUniversity，skip 已存在 slug/moe_code）
  → tmp/verify-universities.cjs（读回核对总数/省份分布/标识码唯一）
```

骨架字段：slug/moe_code/name/province/city/is_undergrad/nature/affiliation/founding_year/website/tags（名单内可机器判定的：公办民办、本专科；双一流/985/211 按 147/39/116 官方名单 join）。

### 6.2 Enrichment（批量滚动，复用数据债自动化）

- 方向 1 `universities-content`：双一流 147 所 content 补全（概览 80~200 字 + 办学成就 list，格式与学校研究稿一致，含 contentOverviewBlocks）
- 方向 2 `universities-lines`：双一流 × 上海/江苏 2026 线（各省考试院官方口径；自媒体汇总一律 `verified:false` 且只进 note，不进 min）
- 写库脚本：`tmp/apply-universities-batch.cjs`（对标 apply-spotcheck-generic：scoreLines 复合键合并只增不覆盖、content 幂等、DRY→exec→读回验证）
- **挂进每日数据债自动化**：`tmp/generate-daily-task.cjs` 加 universities 方向（P1 级，排在弱市攻坚 P1W 之后），四城学校债清零后高校自动接棒成为主战场

### 6.3 红线（继承学校频道）
禁止编造数字；查无留空并记 notes；分数线复合键只增不覆盖；写库前 DRY、写库后读回验证；metrics 键白名单。

## 8. API

`app/api/[...slug]/route.js`（现有 api-router）扩展：

- `GET /api/universities?province=&tags=&q=&page=` → 列表（瘦列，同 SCHOOLS_LIST_COLUMNS 纪律：排除 content/score_lines）

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 更名潮（独立学院转设/民转公）导致 slug/校名漂移 | moe_code 做稳定锚点；aliases 记录曾用名；名录更新时 diff moe_code 而非校名 |
| 同名跨省高校（如多所"XX学院"） | slug 含省份天然消歧；导入时 slug 冲突即 fail-fast 人工复核 |
| 分省录取线数据量爆炸 | v1 限定双一流×核心省；jsonb 复合键；扩量前（>5 万条）拆独立表 `university_score_lines` |
| 第五轮学科评估未官方公开 | 只录第四轮（2017 官方公开口径）；词表锁定 round:4 |
| 2868 详情页 ISR 首访冷启动 | CDN 边缘缓存 + 列表页导流；必要时 build 后跑一次批量 warm-up 脚本 |
| 商业排名版权 | 一律不收录（软科/校友会/QS），只收官方口径 |
