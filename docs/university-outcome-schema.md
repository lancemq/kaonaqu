# 高校 outcome_stats 字段口径（2026-11-26 建立）

> 背景：11-26 审计发现 `universities.outcome_stats` 2952 所全空，高校详情页无成果可展示。
> 本文件定义高校侧结构化成果字段（与中学 `outcome_stats` 分开，勿混用），作为采集与展示的唯一口径。

## 一、结构

```js
[{
  exam: '就业质量',                 // 当前受控值：就业质量（未来可扩「升学质量」「学科成果」）
  kind: '本科教学质量报告',          // 受控：本科教学质量报告 | 就业质量报告 | 官微公布
  year: 2024,                       // 毕业届别（Number）
  verified: true,                   // true=学校官方报告/官微；false=媒体转述或第三方
  source: '复旦大学2023-2024本科教学质量报告',
  sourceUrl: 'https://jwc.fudan.edu.cn/...',
  metrics: {
    employmentRate: 90.23,          // 毕业去向落实率/就业率（%）
    furtherStudyRate: 74.7,         // 继续深造率（%）
    domesticRate: 54.44,            // 国内深造率（%）
    overseasRate: 23.77,            // 出国(境)深造率（%）
    directPhDRate: 20.07            // 直博比例（%）
  },
  note: '截至2024年8月，本科毕业生3328人（不含港澳台侨、留学生）'
}]
```

## 二、口径规则（红线）

1. **只录官方公布值**：来源限学校官网/官微发布的本科教学质量报告、就业质量报告、官微就业数据。第三方（搜狗聚合、排名站、自媒体估算）一律不录。
2. **查无留空**：官方未公布的分项（如复旦未单列国内/出国境深造），对应 metrics 字段留空（`null` 或不写），不得用其他来源补齐，不得推算。
3. **统计口径入 note**：毕业人数、统计截止时间、是否含医学院等口径差异必须写进 note。
4. **去重键**：`exam + kind + year`；同一届同一来源只保留一条，新年份只增不覆盖。
5. **verified**：官方原文 true；仅经媒体转述但数字明确、出处为官方报告的，可标 true 并在 source 注明「官微/报告（媒体转载）」；其余 false。
6. **track 差异**：校本部/医学院数据有别时，取校本部口径并在 note 说明。

## 三、当前进度

- 2026-11-26 首批：复旦大学、上海交通大学（2024 届，上海 985）。
- 待扩：同济大学、华东师范大学等双一流头部校；后续由每日高校分配器 `ug-outcome` 方向轮转。
